# 글링 스토어 스크린샷 보강 조사 — 2026-09-21

요청: 로딩·메인·모임 등 실제 앱 경험을 폭넓게 소개하고, Mobbin 계정/MCP를 참고한다. 새 빌드 배포와 병행. 현재 등록된 3장은 빌드 6의 밴쿠버 피드·토론토 피드·도시 선택이라 최신 모임 기능을 설명하지 못한다.

## 확인한 원칙

- Apple: 실제 앱 UI를 사용해 경험을 전달. 미리보기 영상이 없으면 검색 결과에 첫 1~3장이 노출될 수 있으므로 핵심 경험을 앞에 배치. https://developer.apple.com/app-store/product-page/
- Apple: 승인 후 일반 스크린샷 변경은 새 버전이 필요. https://developer.apple.com/help/app-store-connect/manage-app-information/upload-app-previews-and-screenshots
- Google: 앱을 차별화하는 실제 인앱 경험을 보여줄 것. https://support.google.com/googleplay/android-developer/answer/13393723
- 플랫폼별 캡처/해상도 검증. Android에 iPhone 프레임을 쓰지 않음. 실제 제공 기능만 표현하고 후기·참여자 수를 성과 증거로 꾸미지 않음.
- BrandKit 확인: 종이 #FAF9F5, 잉크 #21252C, 절제된 인주 #BE3B2A, 동네 저널. 폰트/자산 YAML 파싱 경고가 있어 현재 앱 자산을 기준으로 함.

## 제안 순서 (제작·업로드 전 구성안)

| 순서 | 실제 화면 | 전달할 가치 / 문구 초안 |
|---|---|---|
| 1 | 메인 피드 | 캐나다 일상, 한국어로 편하게 |
| 2 | 모임 목록 | 함께할 이웃을 찾아보세요 |
| 3 | 모임 상세·참여 | 어떤 모임인지 살펴보고, 참여해요 |
| 4 | 일회성·정기 모임 | 한 번의 만남도, 꾸준한 모임도 |
| 5 | 대화 | 만남 전후의 이야기도 글링에서 |
| 6 | 글 작성·사진 | 사진과 함께 나누는 동네 이야기 |
| 7 | 로딩 브랜드 화면 + 메인 | 우리 동네의 오늘을 펼치다 |

한 장에 하나의 가치와 읽기 쉬운 짧은 제목을 배치하는 것은 디자인 제안이며 전환율 개선이 입증된 결과가 아니다. 로딩 화면만 단독 첫 장으로 쓰기보다 마지막 브랜드 장 또는 영상 도입부로 활용한다. 장마다 같은 배경/서체/프레임을 쓰고 실제 화면 크기를 충분히 확보한다. 캡처의 개인정보·실제 대화는 노출하지 않는다.

## Mobbin 조사 상태

Kroma의 Mobbin 소스 검색은 SERPER_API_KEY 미설정으로 실패. 이를 Mobbin 계정 문제로 혼동하지 않는다. 공식 Mobbin MCP `https://api.mobbin.com/mcp`는 Codex에 등록되어 있으나 미로그인 상태임을 확인하고 공식 OAuth 연결을 시작했다. Google 계정 선택이 필요해 소유자에게 사용하는 이메일을 질문한 상태. MCP 실조회 전까지 Mobbin 최신 사례를 확인했다고 주장하지 않는다.

기존 9/9 조사에서 직접 이미지 확인한 자료는 tasks/community-direction-2026-09-09.md에 기록됨: 당근 커뮤니티 flow a846e754-560e-401a-ace5-8b2190962039, 모임 상세 flow 87889a52-16bc-4a54-86cb-8bfefc073c42. 이번 조회는 웹 추출 실패로 새 검증이 아님.

## 1.0.2 스크린샷 교체 작업

사용자 요청으로 1.0.2(33) 심사를 회수. API `DEVELOPER_REJECTED` 확인. 기존 한국어 APP_IPHONE_67 세트의 3장은 서로 체크섬이 다르지만 두 피드의 구성이 유사하다. 원본 3장과 원격 목록을 `/tmp/gling-screenshots-before-backup` 및 `/tmp/gling-screenshots-before.json`에 백업했다.

BrandKit의 글링 동네 저널 브랜드를 다시 확인했다. Mobbin 로그인 연결이 이제 동작하며 [Meetup 이벤트 상세](https://mobbin.com/screens/e32776bc-2760-43af-b2e9-9c7d1513d353)를 실제 이미지로 확인했다. 모임 제목·일시·장소·참여 행동이 한 화면에서 읽히는 구성을 참고하되 타사 화면을 글링 캡처에 사용하지 않는다.

이번 요청은 기존 스토어 자산 보강이므로 별도 편집기나 앱 UI를 새로 만들지 않고 실제 iOS 캡처를 사용한다. 새 이미지 업로드 후 원격 COMPLETE와 순서를 검증한다. 재제출 전까지 회수 상태를 유지한다.

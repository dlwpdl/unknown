# 글링 오늘·지도·로고·카테고리 후속

2026-10-08 사용자 승인 변경. 오늘 카드는 작성자·시간 → 카테고리·제목 → 첨부 사진 → 본문 순서다. 공통 카테고리는 맛집 → 비즈니스 → 여행이며 기존 ID와 예시 글의 분류를 유지한다. 밝은 화면 로고는 같은 벡터의 검은 글자·기존 금색 점·투명 배경이고, 어두운 화면은 기존 밝은 글자를 쓴다.

[클릭 가능한 HTML 시안](index.html)은 실제 PostCard·GlingLoader를 React Native Web으로 렌더한다. 예시 데이터이며 필터·테마·지도 입력을 확인할 수 있다. 나머지 게시글 행동은 앱에서 사용한다. render.mjs로 다시 생성할 수 있다. native-card-final.png는 이전 iOS 카드 순서 확인의 부분 캡처이며 이번 밝은 로고·지도 게시의 실제 기기 검증은 아니다.

Google 지도 링크는 글쓰기에 선택 입력하며 피드·상세·공개 웹에 외부 지도 이동을 표시한다. HTTPS·Google 지도 도메인과 경로, 지도 포함 본문 4,000자를 검증한다. 원고 보존·오류 안내·44px 터치 영역·기존 소리/햅틱을 유지한다. 새 지도 API 키나 위치 권한은 추가하지 않는다. 자세한 저장 규칙과 한계는 [지도 링크 명세](../../../docs/specs/post-map-links.md)를 참고한다.

최신 origin/mobile-app 기반 격리 체크아웃에서 TypeScript·린트·전체 테스트317개와 공개 웹 export를 확인했다. 기존 UI 시안은 1440/390/320px 순서·필터·테마·가로 넘침 없음을 확인했다. 로고 변형은 원본 SVG의 글자 fill만 변경해 렌더했으며 알파·금색 점·모양이 동일하다. Apple Design과 시안에 연결한 Mobbin 화면을 적용했다.

커밋 전 실제 공개 웹 검사에서 초기 HTML의 내용 누락을 발견했다. 공용 피드백의 오디오 초기화가 정적 렌더에 들어가지 않도록, 데이터를 가져온 게시글 목록·상세에만 기존 피드백 Provider를 적용했다. 지도와 기존 업체 CTA는 같은 피드백을 유지한다. 수정 후 실제 export와 브랜드·공개 경로·관리자/채팅 코드 제외 검사를 통과했다.

공유 체크아웃의 다른 사용자 변경은 보존한다. 커밋·푸시는 앱/서버/스토어 배포와 구분한다. 이번 업무에서는 외부 게시·모임 취소·서버 마이그레이션·스토어 제출을 하지 않았다. 새 지도 행동 분석 식별자는 0125 마이그레이션에 준비되어 있다.

자연스러운 두 개의 입구.

추천 · 대화 통합 + 모임에서 바로 열기

모임은 소개와 가입을 살피는 곳.
채팅은 내 대화를 모아 보는 곳.
어디서 대화를 열어도, 뒤로 가면 들어온 자리로 돌아와요.

공개 여부와 가입 상태는 별개

내 모임 / 둘러보기로 목록을 나눕니다. 공개 모임에도 ‘가입됨·신청 중’이 붙을 수 있어요. 가입한 비공개 모임은 내 모임에서 찾고, 대화는 가입이 완료된 멤버만 엽니다.

방식이용 흐름과 판단
모임 안에서만 대화모임과 대화가 가까워요. 여러 모임의 새 메시지는 각각 찾아가야 해요.
채팅 탭으로 강제 전환대화 목록은 한곳에 모여요. 모임을 보던 위치로 돌아가는 과정이 끊겨요.
통합 대화 + 두 입구
추천		채팅에서 전체·모임·개인 대화를 모아 봐요. 모임에서도 같은 방을 바로 열고, 원래 목록과 스크롤로 돌아와요.

시안에서 직접 확인하기

  1. 내 모임의 퇴근길 30분 산책 → 대화 열기. 메시지를 적고 보내기를 누른 뒤, 왼쪽 위 ‘모임’으로 돌아오세요.
  2. 하단 채팅 → 모임 → 퇴근길 30분 산책. 같은 기록과 읽음 상태를 확인하고 ‘채팅’으로 돌아오세요.
  3. 모임 → 둘러보기 → 주말 한 끼 같이 → 소개 열기 → 참여 신청. 신청 중으로 바뀌고 대화 입구는 생기지 않아요.

시안 범위와 근거

모임·채팅 동선만 동작하는 로컬 시안입니다. 메시지와 참여 신청은 이 파일 안에서만 바뀌며, 실제 사람에게 전송하거나 서버에 저장하지 않습니다. 새로고침하면 초기화됩니다.

Lex의 Explore Groups / Your Groups와 Joined 표시, WhatsApp의 개인·그룹 대화 목록과 필터를 참고했습니다. 두 입구에서 같은 방을 열고 복귀하는 동선은 글링을 위한 제안입니다.

Apple의 탭별 탐색 상태 보존과 짧고 단순한 모달 사용 원칙에 맞춰, 대화는 모달을 중첩하지 않고 현재 탭 안에서 엽니다. 44pt 이상의 터치 영역과 동작 줄이기를 적용했습니다.

현재 실제 앱은 모임 승인 시 주최자와의 1:1 대화만 생성하므로, 이 안을 적용하려면 그룹 멤버십과 공통 모임방 구현이 추가로 필요합니다.

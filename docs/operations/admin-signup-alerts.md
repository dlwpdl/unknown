- `create_profile_with_consent`에서 처음 프로필을 만들고 필수 동의를 완료하면 활성 admin에게 `admin_signup` 시스템 알림을 만든다. 기존/재활성화 프로필의 업데이트와 시드·익명 계정은 제외한다. 실패한 가입 트랜잭션은 알림과 푸시 작업도 함께 롤백한다.
- 기존 `private.notify_admins`와 기기 등록·알림 설정·푸시 큐를 사용한다. `(user_id,target_id)`의 가입 전용 고유 인덱스가 중복을 막는다. 이메일·실명·생년월일·IP를 본문에 넣지 않는다.
- 앱의 기존 관리자 알림함과 배지에서 보인다. 푸시 허용·유효한 등록 기기가 있으면 기존 분 단위 푸시 작업이 전송한다. 탭하면 기존 `/admin?section=users` 경로를 사용한다.
- 관리자 웹 전체 섹션에서 본인 미확인 가입 알림을 확인한다. 실시간 이벤트와 30초 재조회/창 복귀로 갱신한다. 회원 보기에는 기존 감사 기록이 적용되며 확인 실패 시 알림을 지우지 않는다. 읽음 상태는 기존 앱 알림함과 공유한다.
- 관리자 웹은 기존 `127.0.0.1:54321` 서버다. 기존 Tailscale HTTPS 프록시도 이 포트를 가리킨다. 서버가 꺼져 있으면 저장소에서 `npm run admin`으로 기존 방식대로 실행한다.

# 필수 앱 업데이트

앱은 새로 시작할 때 설치된 네이티브 빌드 번호를 `public.app_release_policy`의 플랫폼별 `minimum_build`와 비교한다. 더 낮으면 앱 전체를 가리고 스토어 업데이트 버튼을 보여준다. 작성 중인 초안을 강제로 가리지 않도록 실행 중인 세션에서는 확인하지 않는다. 웹과 Expo Go는 대상이 아니다. 네트워크나 정책 조회가 실패하면 장애로 앱 전체가 잠기지 않도록 이번 실행은 통과시킨다.

최소 빌드는 현재 iOS·Android 모두 50으로 시작한다. **새 빌드가 해당 스토어에서 실제로 설치 가능해진 뒤에만** 그 플랫폼의 값을 올린다. iOS 수동 출시와 Android 비공개 테스트는 각각 별도로 확인한다. 예를 들어 iOS 빌드 51이 공개되었다면:

```sql
update public.app_release_policy
set minimum_build = 51
where platform = 'ios' and minimum_build < 51;
```

릴리스마다 스토어 설치 가능 여부를 확인하고 이 값을 갱신한다. 실수로 높였다면 이전 값으로 되돌려 즉시 차단을 해제할 수 있다. 1.0.3 이하처럼 이 확인 코드가 없는 기존 바이너리는 소급 차단할 수 없으며, 장치가 포함된 빌드가 배포된 뒤부터 작동한다.

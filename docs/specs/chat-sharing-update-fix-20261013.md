# 채팅 사진·위치 공유와 빌드 직후 구버전 차단 · 2026-10-13

사용자 지시: 두 플랫폼의 구버전을 새 릴리스 빌드 성공 직후 자동 차단한다. 스토어 공개를 기다리는 기존 정책을 대체한다. 기존 릴리스 작업의 서명 검증 다음 단계에서 플랫폼별 최소 빌드를 원자적으로 올리고 재조회한 뒤 심사 제출한다. 서비스 키는 이 단계에만 전달한다. 심사 중에도 차단되므로 설치 가능할 때까지 사용자가 기다릴 수 있다. 현재 성공한1.2.0(64)에 두 플랫폼 최소64를 실제 적용했다.

1:1 대화의 사진은 기존 OS 선택기에서 최대20장을 순서대로 골라 기존 압축·비공개 Storage·안전 감시 RPC 경로로 한 장씩 전송한다. 전송이 확인된 사진을 선택 목록에서 즉시 빼며 실패하면 나머지를 유지한다. 미리보기에서 사진 확대·개별 제외·전체 취소를 지원하며 작성 중인 메시지를 보존한다. 서버의1초 전송 간격도 유지한다. 새 DB·SDK·의존성은 없다.

채팅 위치는 키가 필요한 별도 Google Maps/Places 경로를 삭제하고 승인된 게시글의 MapLibre/원격 지도 오류·재시도·출처 처리 컴포넌트를 재사용한다. 전체 화면 대신82%·최대640 높이의 하단 시트이며 큰 글자와 키보드에서 내용이 스크롤된다. 장소 검색은 기존 OS 지오코더, GPS는 명시적인 버튼에서만 전경 일회성 권한과15초 제한을 사용한다. 좌표 범위·최근2분/250m 이내 정확도·모의 위치를 검증하고 취소/백그라운드/직접 핀 선택 뒤 늦은 응답을 폐기한다. 실패한 위치 전송은 선택을 보존한다.

후속 사용자 지시에 따라 Design 스킬로 첨부 메뉴·사진 확인·위치 공유를 함께 다듬었다. 기존 글링 나이트 색상과 라일락 강조색을 유지하고 큰 그림자를 줄였다. 첨부 메뉴는 설명이 있는 두 행, 사진은 확대 버튼과 별도44px 삭제 버튼, 위치는 검색·지도·장소·단일48px 전송 버튼 순서다. 모든 바뀐 행동은 기존 인터랙션 피드백을 사용한다. 키보드가 올라오면 사진 패널과 위치 시트가 줄어들고 내부 내용을 스크롤한다. 장식 아이콘은 화면 읽기에서 제외한다.

Apple Design과 실제 Mobbin 화면을 확인했다: [Urban Company 첨부 목록](https://mobbin.com/screens/e8cd488e-3da3-4b7e-b238-40d3863d60e4), [WhatsApp 사진 확인](https://mobbin.com/screens/14a81cbb-3c19-40c0-ae6f-32a0347a0a4d), [Telegram 위치 시트](https://mobbin.com/screens/7ad09462-882d-4b7e-b238-40d3863d60e4). 시안은 output/design/chat-sharing-update-fix-20261013/index.html이며 Git → gling 소속 Orca Browser 탭에서 표시했다. 시안 지도 이미지는 기존 MapLibre HTML을 실제 렌더해 캡처했다. 시안의 검색·GPS·전송은 예시 동작이며 메시지를 게시하거나 권한을 요청하지 않는다. 앱의 실제 GPS/햅틱/키보드는 실기기 검증과 구분한다. 디자인 검사기의 지도 full-bleed와 휴대폰 프레임 clipping 경고는 의도된 시안 표현이다.

후속 크기 조정: 사용자는 전체 시안에 만족한다고 확인한 뒤 첨부 메뉴의 “사진 보내기 / 위치 공유하기” 버튼이 크다고 정정했다. 두 항목을64px에서48px, 아이콘 배경을40px에서32px로 줄이고 설명을 한 줄로 정리했다. 터치 영역은48px이며 기존 동작·피드백을 유지한다. 1.2.1 릴리스는 공통 검사 단계에서 중단했고 이 조정을 포함한1.2.2로 빌드·제출한다.

# 채팅 사진·위치 공유와 빌드 직후 구버전 차단 · 2026-10-13

사용자 지시: 두 플랫폼의 구버전을 새 릴리스 빌드 성공 직후 자동 차단한다. 스토어 공개를 기다리는 기존 정책을 대체한다. 기존 릴리스 작업의 서명 검증 다음 단계에서 플랫폼별 최소 빌드를 원자적으로 올리고 재조회한 뒤 심사 제출한다. 서비스 키는 이 단계에만 전달한다. 심사 중에도 차단되므로 설치 가능할 때까지 사용자가 기다릴 수 있다. 현재 성공한1.2.0(64)에 두 플랫폼 최소64를 실제 적용했다.

1:1 대화의 사진은 기존 OS 선택기에서 최대20장을 순서대로 골라 기존 압축·비공개 Storage·안전 감시 RPC 경로로 한 장씩 전송한다. 전송이 확인된 사진을 선택 목록에서 즉시 빼며 실패하면 나머지를 유지한다. 미리보기에서 개별 제외·전체 취소를 지원한다. 새 DB·SDK·의존성은 없다.

채팅 위치는 키가 필요한 별도 Google Maps/Places 경로를 삭제하고 승인된 게시글의 MapLibre/원격 지도 오류·재시도·출처 처리 컴포넌트를 재사용한다. 전체 화면 대신82%·최대640 높이의 하단 시트이며 큰 글자와 키보드에서 내용이 스크롤된다. 장소 검색은 기존 OS 지오코더, GPS는 명시적인 버튼에서만 전경 일회성 권한과15초 제한을 사용한다. 좌표 범위·최근2분/250m 이내 정확도·모의 위치를 검증하고 취소/백그라운드/직접 핀 선택 뒤 늦은 응답을 폐기한다. 실패한 위치 전송은 선택을 보존한다.

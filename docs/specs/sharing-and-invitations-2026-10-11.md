# 글링 공유·초대와 로그인 경계

사용자가 승인한 시안대로 게시물·페스티벌·모임을 외부 공유, 링크 복사, 기존 글링 대화 전송으로 나눈다. 수신 대화에는 글링 소유 URL만 제목·대표 이미지·도시·공개 일정 카드로 표시한다. 본문·댓글·추가 사진·상세 집결 정보는 로그인 후 확인하며, 초대 링크는 기존 신청·모임장 승인 절차를 우회하지 않는다. 발송은 사용자가 대화를 선택했을 때만 실행한다.

기존 OS 공유·브라우저 복사·대화 목록/메시지 RPC·Google/소셜 로그인·모임 신청·권한을 재사용한다. 공유에는 제목과 링크만 넣는다. 로그인 복원·실패·취소·계정 변경 및 요청 경합에서 원래 글과 사용자 입력을 유지하고 이전 계정의 본문·대화를 숨긴다. 전송 결과가 불확실하면 자동 재전송하지 않는다. 웹의 행사 확인은 검증된 Ticketmaster 판매처로 연결한다.

Apple Design의 44px 조작 영역·즉시 피드백과 실제 Mobbin Once 초대 화면 https://mobbin.com/screens/0612120c-8ad7-4581-828c-fb8face6ac9c 의 대표 이미지·제목·주 행동, Givingli https://mobbin.com/screens/c023134b-53f7-4404-b13c-d700a9ff11e1 의 일정 정보 순서를 기존 night/iris에 적용했다. 승인된 HTML 시안은 원 작업 폴더 output/design에 보존한다. 새 의존성·계정·추천인 테이블·예약 작업·이미지 생성은 필요 없다.

## 서버와 운영 적용

20261011193000은 최소 공개 미리보기 RPC를 추가한다. 20261011194000은 기존 공개 독자 함수의 익명 본문·추가 사진·상세 집결 정보와 댓글 권한을 제한한다. 기존 인증된 읽기·삭제·차단·신고·비즈니스 게시물 바인딩·전체 콘텐츠 안전 분석·관리자 MFA와 감사는 유지한다. 적용은 운영 함수 정의/권한 해시가 일치하는 두 migration만 guarded transaction으로 진행하며, 전체 pending migration을 일괄 적용하지 않는다. 기존 public-post Edge의 HTML/Markdown도 metadata만 반환한다.

현재 GitHub Pages에서 정상 응답하는 기본 링크 /post?id=UUID를 유지한다. Supabase 기본 Edge HTML은 text/plain으로 바뀌므로 기본 공유 목적지로 사용하지 않는다. /share/UUID와 /post/UUID는 기존 링크의 클라이언트 복귀만 지원한다. 링크별 raw OG HTML을 제공하는 같은 도메인 서버 연결은 아직 미확정이며 별도 서버·DNS·유료 서비스를 만들지 않는다. 이 연결과 실제 외부 메신저 미리보기는 기능 코드/웹 배포 완료와 별도다.

## 검증과 릴리스

기존 공유/인증/채팅/모임 회귀 검사, 전체 Node 검사, 타입·lint, 공개/비즈니스 웹 export와 개인정보·관리자 경계 검사를 수행한다. 실제 React에서는 모든 외부 응답을 가로챈 모의 OAuth·사진·메시지로 로그인→원래 글→선택 공유·신청을 검증한다. 실제 계정 로그인·메시지 발송·모임 승인이나 기기 조작으로 표현하지 않는다.

compact gallery 및 pan/pinch는 별도 gallery 담당자의 최종 commit을 재사용한다. 네이티브 1.1.9 tag/build/store 제출은 기존 gallery 릴리스 담당자 한 곳에서 두 PR 통합과 CI 확인 후 진행한다. 기존 Android 1.1.8 internal 제출과 Apple build59 beta review는 보존한다. 공유 PR은 앱 버전·태그·스토어 제출을 변경하지 않는다.

# 글링 공유·외부 초대

2026-10-11 사용자 요청: 사용자 리뷰 작업을 마친 뒤 게시물·페스티벌·모임을 글링 내부와 외부로 공유한다. 링크에는 대상별 제목·대표 이미지·공개 일정이 담긴 미리보기 카드가 보이고, 본문과 참여는 Google·소셜 로그인 후 이어진다. 모임장과 기존 회원의 링크 초대는 기존 가입 신청·호스트 승인 절차를 유지한다.

기본 준비 기준: 웹의 상세 본문까지 로그인 필수. 기존 공개 웹 유지 여부는 선택 질문으로 확인 중이며 답변이 오면 적용 범위를 따른다. 공개 제목·도시·대표 이미지·공개 일정과 본문/댓글/승인된 모임의 상세 집결 정보는 구분한다. 초대 URL은 참가 권한이나 신원 인증이 아니다.

구현: 기존 공유 URL·OS 공유 시트·대화 목록/메시지 RPC·Google/카카오/Apple 로그인·모임 신청을 재사용한다. 공유 시트에 외부 공유/링크 복사/글링 대화로 보내기를 제공하고, 수신 대화에는 허용된 글링 URL만 카드로 표시한다. 다른 사람에게 실제 메시지를 보내는 것은 화면의 명시적 선택 때만 실행한다. 로그인 취소·실패·재시도·새 계정 전환 시 기존 링크와 입력을 유지하고 다른 계정의 캐시를 숨긴다.

서버: 최소 공개 미리보기 RPC, 인증 전 본문 접근 차단, 댓글/Markdown/간접 공개 함수·이미지 권한 점검. 기존 삭제/숨김/신고/차단/모임 승인·전체 콘텐츠 안전 분석/MFA·감사 경계를 유지한다. 미리보기 입력/URL/HTML은 불신하고 외부 임의 URL 서버 fetch를 허용하지 않는다.

외부 카드: GitHub Pages는 서버 렌더링이 없고 Supabase Edge HTML은 기본 도메인에서 text/plain으로 바뀐다. 따라서 /share/:UUID의 서버 HTML을 위한 작은 표준 Fetch 기반 게이트웨이를 별도로 준비하고 HTML 원문에 OG 정보를 넣는다. 설치·새 의존성·원격 배포를 하지 않는다. 실제 도메인 라우팅과 각 메신저의 미리보기 수락은 코드/로컬 시험과 별도로 기록한다.

디자인: 현재 글링 night/iris, Apple Design의 익숙한 선택·44px 컨트롤·즉시 피드백, Mobbin Once 초대 화면(https://mobbin.com/screens/0612120c-8ad7-4581-828c-fb8face6ac9c)의 대표 이미지/제목/한 행동과 Givingli(https://mobbin.com/screens/c023134b-53f7-4404-b13c-d700a9ff11e1)의 일정 정보 순서를 적용한다. 임의의 초대자·참석자·성과를 만들지 않는다.

검사: `npm test`, `npm run typecheck`, 변경 ESLint, 독립 Node RPC/UI/OG 검사, 롤백 pgTAP, 320/390/768/1440px 및 큰 글자 시안·상호작용, 공개/앱 웹 export. 운영 로그인·실제 메시지·초대 승인·공개 카드·배포 증거는 각각 구분한다. 현재 코드 패턴을 따르고 새로운 패키지/토큰·추천인 테이블/예약 작업을 추가하지 않는다.

구현·로컬 검증 결과: 사용자 리뷰는 직접 입력한 1–10점(0.5점 간격), 공개 평균은 소수 한 자리로 표시한다. 기존 100점 행동 집계는 구 클라이언트 호환용으로 보존하며 직접 리뷰 점수로 환산하지 않는다. 공유 화면은 실제 선택 후 OS 공유·링크 복사·기존 대화 전송을 실행하고, 전송 여부가 불확실하면 중복 전송 대신 해당 대화 확인을 안내한다. 웹에 모임 신청·프로필·신청서·채팅 경로를 연결하고, 앱 전용 전체 프로필/계정 설정 버튼은 웹에 노출하지 않는다. 웹의 행사 확인은 검증된 Ticketmaster 판매처 링크로 연다.

인증 경계: 서버는 익명 본문·댓글을 차단하고 유효한 소셜 JWT의 기존 인증된 읽기 권한은 유지한다. 앱 UI는 활성 프로필 및 기존 가입·동의 완료까지 기다린다. 느린 세션 복원 때 중복 로그인 창을 띄우지 않으며 계정 전환/로그아웃은 이전 계정의 본문·대화·신청 정보를 숨긴다. 링크 자체는 신청·승인·모임 대화 권한을 만들지 않는다.

최종 근거: `output/qa/shared-links-2026-10-11/verification.json`. 운영 반영은 미완료다. 공유용 서버 HTML `/share/*`를 같은 운영 도메인에 연결해야 실제 외부 OG 카드가 된다. 기존 `supabase/config.toml`에는 루트 및 업체 웹 OAuth callback이 있지만 실제 운영 제공자 설정과 반환은 별도 확인해야 한다. 호환 가능한 리뷰/미리보기 RPC를 먼저 준비하고 업데이트된 앱·웹과 익명 콘텐츠 게이트의 반영을 맞춰야 한다. 구버전 익명 상세 화면은 댓글 RPC 권한 변경 후 업데이트 전까지 기존 오류 안내를 표시할 수 있다. 기존 signed 이미지 URL은 원래 만료까지 유효하다. 폴더 selector 오류로 다른 Orca workspace나 진행 중인 탭을 재사용하지 않았으며 시안·빌드는 격리된 브라우저에서 검사했다.

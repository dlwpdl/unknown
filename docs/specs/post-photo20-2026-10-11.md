# 글링 전체 카테고리 사진 20장 (2026-10-11)

사용자 지시: 전체 카테고리에서 20장 업로드, 최적화, 승인한 Port Coquitlam 매물의 Craigslist 원문 20장 모두 포함. 현재 공통 업로드/작성/수정/업체 초안/업체 MCP/API 및 posts 체크의 10장 한도를 20장으로 변경하며 21장은 거부한다. Instagram 6~10장과 네이버 카페 6장의 별도 계약·일정은 유지한다.

기존 1280px WebP·480px 썸네일·2MiB 파일 상한을 유지한다. 업로드는 최대 3개씩 진행하고 선택 순서를 유지한다. 실패하면 진행 중인 요청이 끝난 뒤 새 성공 파일만 정리한다. 기존 사진/불확실한 저장 결과는 삭제하지 않는다. 상세 갤러리는 현재 사진과 앞뒤 사진만 요청하고 20장의 스크롤 위치·피드백·접근성을 유지한다.

검증: 경계/순서/동시성/실패 정리/업체 MCP 및 갤러리 실제 렌더 트리 44개; 기존 전체 테스트 623개 중 622 통과·기존 1 skip; TypeScript·변경 파일 ESLint 통과. 운영 DB transaction rollback에서 12개 게시글 카테고리의 story/listing 작성20·수정20·21장 차단과 소유권/중복/테이블 제약 78개 통과. 실제 게시와 배포 readback은 output/qa/post-photo20-2026-10-11 및 output/design/gling-port-coquitlam-warehouse-2026-10-11에 저장한다.

통제된 요청당 20ms 조건의 원문 20장 비교: 순차 처리 중앙값965ms → 3개 동시352ms, 약63.5% 감소. 실제 운영망/실기기 속도 개선폭은 별도다.

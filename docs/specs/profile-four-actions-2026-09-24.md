# 프로필 관리 버튼 4개 정리 — 2026-09-24

## 목표

프로필의 멤버십·인증·알림·저장한 글을 같은 스택 탐색 방식으로 열고, 각 화면에서 현재 상태와 다음 행동을 바로 알 수 있게 한다. 기존 멤버십 화면의 가격·제한·구매 동작은 유지한다.

## 화면 계약

- 인증: 실제 `verification_level`을 현재 단계로 표시한다. Lv1은 소셜 로그인 확인이며 실명·나이 인증이 아니다. Lv2 전화번호 명의 확인과 Lv3 신분증·얼굴 대조는 예정 기준으로 설명하고, 신청 기능이 없으므로 신청 버튼을 만들지 않는다. 현재 DB 값만으로 미도입 검증 완료를 주장하지 않는다.
- 알림: 기존 개인/관리자 필터와 권한 구분을 유지한다. 읽지 않은 알림을 먼저 보여주고, 목록 진입 시 기존 읽음 처리 동작을 유지한다. 빈 화면·오류는 공통 상태 카드를 쓴다.
- 저장한 글: 중첩 시트를 독립 스택 화면으로 바꾸고 기존 저장 목록과 글 상세를 재사용한다. 다시 들어올 때 목록을 새로 읽어 저장 해제·삭제를 반영한다.
- 프로필: 네 버튼 모두 같은 눌림 피드백과 뒤로가기 동선을 가진다.

## 구현·검증

Expo Router, 기존 테마·컴포넌트·RPC만 사용한다. 새 서버 API·인증 업체·의존성은 추가하지 않는다. `npx tsc --noEmit`, 관련 Node 테스트, `npm test`, 시뮬레이터와 HTML 시안으로 확인한다. 실제 운영 인증 단계 변경과 앱 심사 제출은 범위 밖이다.

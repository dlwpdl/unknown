# 통합 지도 TOP 25 · 승인 A안

2026-10-15 사용자: “a안으로 진행시켜”. 기존 지도에 카테고리 색을 유지한 작은 금빛 플래그를 붙인다. 선택한 핀·카드·목록에는 TOP 25 전체 배지를 표시한다. TOP 25는 별도 카테고리가 아닌 독립 필터다.

이번 범위는 앱의 배지·필터·확인된 장소 통합 동작이다. 실제 도시별 25곳 목록은 아직 없으므로 앱의 편집 목록은 비워 둔다. 시안 예시는 테스트/로컬 검수에만 쓴다. 임의의 순위, 인기 통계, 외부 업체 데이터, 일반 회원이 작성한 해시태그로 배지를 만들지 않는다. 모든 지원 도시에 같은 코드를 적용한다.

최소 데이터는 앱에서 관리하는 도시별 편집 목록이다. 장소 ID·분류·공개 좌표·이름/주소·선정 이유·확인 가능한 HTTPS 출처·확인한 추천글 ID를 기록한다. 별도 DB/API/유료 지도/패키지를 추가하지 않는다. 한 도시 최대 25곳, 동일 도시·장소 ID와 추천글 연결은 유일해야 한다. 이름이 같거나 근처라는 이유만으로 합치지 않는다. 확인한 공개 글 ID로 연결한 장소만 하나의 핀과 카드로 모으며, 거래 리스팅/다른 도시/행사는 추천 장소로 합치지 않는다. 숨김·차단·만료 등 기존 필터를 먼저 적용해 비공개 글/사진을 끌어오지 않는다. 장소 자체의 공공 정보는 게시물과 구분한다.

변경은 src/lib/city-top25.ts, src/lib/discovery.ts, src/lib/discovery-map-html.ts, src/app/map.tsx와 관련 Node 검사에 한정한다. 기존 구조와 useInteractionFeedback을 재사용하고 외부 길찾기는 그대로 이어간다. 새 필터는 기존 discovery.filter 분석 항목을 사용한다. 500개 지도 상한, 접근성, 공개/비공개 위치 분리는 유지한다.

검사: `node --experimental-strip-types --test scripts/discovery-top25.test.mjs scripts/discovery-map.test.mjs scripts/discovery-screen.test.mjs`, `npm run typecheck`, 변경 파일 eslint, `npm test`, iOS/Android JS export 및 격리한 실제 화면 검수. 새 동작은 먼저 실패하는 검사로 확인한 뒤 구현한다. 테스트의 예시 목록이 실제 앱 목록에 들어가지 않는지 검사한다.

배포 보류는 유지한다. 일반 장소 검색·커뮤니티 후기는 기존 별도 명세의 범위이며 이번 디자인 승인으로 완료 처리하지 않는다. 실제 도시 TOP 25 선정과 출처 검토는 목록 준비 단계에서 진행한다.

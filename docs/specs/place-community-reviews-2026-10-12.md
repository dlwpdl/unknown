# 장소 검색과 커뮤니티 후기 · 2026-10-12

## 확정한 도시 범위

사용자 정정: “이런 기능은 전체도시에 한번에 적용해 똑같이”. 앞서 제안한 밴쿠버 한 도시 시험 출시는 채택하지 않는다. 앱이 지원하는 모든 도시에 같은 장소 검색·상세·후기 작성·후기 조회 기능을 동시에 제공하는 범위다. 도시별 기능 허용 목록이나 일부 도시만의 출시 단계는 만들지 않는다. 이후 추가되는 도시도 공통 도시 목록을 통해 같은 기능을 사용한다. 기존 도시의 개방 상태를 임의로 변경하는 요청으로 해석하지 않는다.

## 목적과 사용 흐름

선택한 도시에서 음식점·카페·레스토랑 등 장소를 검색하고 기본 정보를 확인한 뒤, 그 장소에 글링 회원이 남긴 방문 후기를 모아 본다. 리뷰가 없는 장소도 장소 정보와 후기 없음 상태를 표시하는 것이 원래 요청의 범위다. 리뷰가 쌓인 장소만 검색하는 방식으로 조용히 축소하지 않는다. 등록된 광고 업체만을 대상으로 제한하지 않는다.

장소 선택 → 장소 상세와 커뮤니티 후기 → 후기 작성 또는 위치 첨부 → 같은 좌표로 Google Maps 열기. 한국인에게 유용한 한국어 경험을 모으는 목적이며, 별도의 국적 인증 절차는 요청되지 않았다. 새로 수집한 장소 정보와 앱에 직접 작성한 후기는 출처를 구분한다.

## 현재 구조와 작업 범위

React Native·Expo 앱과 기존 공개 웹, Supabase를 사용한다. `src/lib/mock.ts`의 `CITIES`와 `src/lib/community-city.tsx`의 선택 도시를 재사용한다. 도시마다 별도 화면이나 서버를 만들지 않는다.

기존 MapLibre·OpenFreeMap 위치 첨부와 `src/lib/post-maps.ts`의 Google Maps URL을 재사용한다. `src/lib/merchant-reviews.ts`에는 등록 업체용 후기 구조가 있지만, 승인 업체·소개글에 연결된 권한과 영수증 공개 조건을 일반 장소 후기에 그대로 적용할 수 있다고 가정하지 않는다. 장소 식별·중복 병합과 일반 장소 후기의 공개 기준은 구현 전 구체화해야 한다. 기존 업체 후기의 비공개 자료와 접근 정책은 보존한다.

## 구현 방식과 검사

기존 호출 방식과 타입을 유지한다. 예: `loadMerchantReviews(client, postId, offset, reviewKind)`처럼 공통 함수에 대상과 페이지 정보를 전달하고, 도시마다 복제한 구현을 만들지 않는다.

검사는 모든 지원 도시의 동일 기능 접근, 도시 필터와 동명이점·지점 구분, 도시 변경 뒤 늦은 응답 차단, 후기 없음과 검색 실패 구분, 작성 권한·신고·안전 검사·개인정보 노출 방지를 포함한다. 장소를 구분할 때 작성자가 붙인 표시 이름이나 좌표 문자열만으로 서로 다른 가게를 합치지 않는다. 새 UI는 기존 피드백·접근성·테마와 공통 디자인 과정에 맞춘다.

앱에서의 공통 검사 명령: `npm test`, `npx tsc --noEmit`, 변경 파일 대상 `npx eslint <files>`. DB를 변경한다면 기존 SQL 경계 검사를 먼저 확장한다. 실제 업체 데이터·iOS·Android·웹 동작 검증은 공급원과 구현이 정해진 뒤 진행한다.

## 데이터와 완료 기준

외부 장소 데이터 공급원·가용 범위·검색 방식·비용은 아직 확정하지 않았다. Google Places 데이터의 저장·출처·지도 표시 제한을 무시해 MapLibre용 업체 DB로 복사하지 않는다. 기존 Google Maps 링크 열기는 유료 Places 검색과 별개다. 출처: https://developers.google.com/maps/documentation/places/web-service/policies .

완료는 모든 지원 도시에서 같은 기능이 실제로 작동하고, 해당 도시의 장소와 실제 저장된 커뮤니티 후기가 정확히 연결되는 상태다. 도시마다 업체 정보의 충실도나 후기 수가 같다고 보장하지 않는다. 오류를 0건으로 표시하거나 가짜 후기·예시 업체로 실제 검색 결과를 채우지 않는다.

이번 기록은 도시 범위 정정과 요구사항 정리다. 장소 검색·일반 장소 후기 코드, DB 변경, 외부 API 연결, 스토어 배포는 이 기록만으로 완료된 것이 아니다.

# 모임 후기·매너 평가·추천 대화

사용자 승인: 앞선 정기 모임 후기/개인 평가/안전 설계에 “좋다 진행하고”, 이어 거래·주거·모임 대화에서 추천 문장을 누르면 전송되는 기능을 요청했다. 추가 승인 질문 없이 같은 앱과 기존 서버 경계에 구현한다.

## 범위와 구현 순서

1. 기존 채팅에 출처별 추천 문장과 받는 사람의 답변을 연결한다. 고정 문장으로 시작하며 AI 호출/비용은 추가하지 않는다. 출처는 서버가 실제 대화 당사자와 글 작성자를 대조한다. 자동 전송하지 않고 사용자가 누른 문장만 전송한다. 기존 일반 입력 초안은 유지한다. 중복 클릭/불확실 응답의 재시도는 동일 client ID로 같은 메시지만 재조회한다. 신고·차단·종료·무제한 무료 1:1 정책·기존 전송/안전 트리거를 유지한다.
2. 모임 회차와 참석 확인을 추가한다. 정기 모임장은 날짜/종료 시간을 가진 회차를 만들고 실제 참가자가 체크인한다. 참석자 사이의 확인 또는 관리자 증빙 검토로 평가 권한을 확인한다. 모임장만으로 불리한 후기를 차단할 수 없도록 참석 이의제기를 둔다. 가입 승인·모임 채팅 이력은 현장 참석 증거로 간주하지 않는다. 일회성은 개인 평가만 가능하다.
3. 종료 후 7일 이내 정기 모임 후기를 한 회차당 한 번 받고 같은 모임에 누적한다. 구체적 운영/분위기/설명 일치와 짧은 공개 후기를 받는다. 개인 평가는 약속·존중·경계 존중 항목과 비공개 설명으로 받는다. 대화만 확인된 평가는 대화 매너로 구분한다. 합의된 관계 목적 자체는 위반이 아니다.
4. 개인 원문은 공개하지 않는다. 양쪽 제출 또는 7일 만료 전에는 상대에게 결과를 노출하지 않는다. 공개 매너 집계는 서로 다른 평가자 5명부터, 동일 상대의 반복 영향은 최근 30일 한 건으로 제한한다. 공개 집계는 정상 안전 검토된 평가만 사용하고 의심/신고/이의제기된 부정 평가는 보류한다. 가입 7일 미만이고 인증 2단계 미만인 계정의 긍정 평가도 자동 반영하지 않고 사람 검토로 보낸다. 신규 사용자는 낮은 점수 대신 정보 부족으로 표시한다.
5. 기존 전체 콘텐츠 안전 큐에 후기·개인 평가·관련 증거를 연결한다. AI는 탐지/우선순위만 담당한다. 위협·성희롱·사기·신상 노출 등은 기존 관리자 경보/감사/MFA 경계에서 검토하며 영구 제재/범죄 판단/점수 감점을 AI 단독으로 결정하지 않는다. 신고는 평가 자격 없이 가능하며 차단/퇴장으로 사라지지 않는다. 비즈니스/MCP 계정에는 개인 평가 원문이나 대화 권한을 주지 않는다.
6. 사용자 추가 요청: 서로의 프로필에서 공개 매너 집계·평가 인원과 공개된 `오늘`/`구해요·팔아요` 작성 이력을 볼 수 있게 한다. 판매 완료 상태도 유지한다. `오늘`은 오늘 날짜로 제한하지 않고 글링의 기존 글 분류를 뜻한다. 삭제·비공개·신고 숨김·차단된 글과 대화/신고/개인 평가 원문은 노출하지 않는다. 글 이력과 매너 점수는 신뢰 판단의 참고이며 실제 신원 인증이나 안전 보장을 뜻하지 않는다.

## 안전과 검증

새 테이블은 private 스키마/RLS/직접 권한 차단, 공개 API는 제한된 집계와 검토된 모임 후기만 반환한다. SECURITY DEFINER 함수는 빈 search_path, auth.uid/현재 계정/실제 관계 검증을 사용한다. 자기 평가·위조 회차/상대·타인 대화·참석 미확인·기한 경과·중복·다른 계정으로 재사용되는 요청은 거부한다. 불리한 후기의 정당성 자체를 호스트 승인에 맡기지 않는다. 집계와 안전 신고를 분리하고 관리자 정정/검토 이력을 남긴다. 외부 모델에는 필요한 맥락만 보내고 학습 금지/보관 최소화 및 사용자 고지를 유지한다.

검사: `node --experimental-strip-types --test scripts/chat-suggestions.test.mjs scripts/meetup-reviews.test.mjs`, 기존 채팅/후기 회귀, 롤백하는 로컬 pgTAP, `npm test`, `npm run typecheck`, 관련 ESLint, 공개 웹/비즈니스 웹 경계 export. 실제 DB 배포·원격 함수 재조회·앱 UI 연결·알림 실제 전달은 각각 구분해 기록한다. 기존 운영 데이터에 시험 대화/후기를 만들지 않는다. 운영 변경 전 원격 이력/실행 중 소유자/백업과 이번 migration만의 diff를 확인한다.

실제 프로필 컴포넌트에서 사용자·계정 전환 시 이전 거래/매너 데이터가 남는 문제, 이전 대화 요청의 늦은 응답이 새 화면으로 이동시키는 문제, 열린 글 상세가 이전 계정에 남는 문제, 신고한 글이 캐시된 이력에 남는 문제를 재현하고 수정했다. 사용자·계정·출처별 응답 binding과 요청별 무효화, 기존 신고 숨김 overlay를 재사용한다. 닫기/재열기/로그아웃/타인 프로필 전환, 기간별 참석/평가 권한, 낮은 평점 설명, 중복 클릭·불확실 응답 재시도 회귀 검사를 추가했다.

## 2026-10-11 사용자 정정: 글링 사용자 리뷰, 10점 만점

비즈니스 상품·서비스 리뷰와 같은 10점 평점을 직접 받는다. 1~10점/0.5점 단위, 소수점 한 자리 평균과 기존 10칸 표시를 재사용한다. 만남·대화는 분리하고 5명/최근 30일/상대당 최신 한 건/검토·공개 시점/이의제기·원문 비공개를 유지한다. 5점 이하 또는 부정 행동은 10자 이상 사유와 사람 검토가 필요하다. 이전 행동 질문을 임의 평점으로 만들지 않는다. 기존 앱 계약은 보존하며 새 `rating` 집계와 `write_user_review`를 사용한다.

# 업체 프로필과 대리등록 자료 구분

사용자 지시: 이름이 확인되지 않은 임대 매물을 회사 프로필로 만들지 않는다. 업체 정보가 없어도 글은 게시할 수 있다. 실제 업체는 기존 프로필을 연결한다. 주거 카테고리는 부동산으로 표시하고 #상업용/#주거용 필터를 둔다. 승인한 창고 글의20장 사진·본문·조회·문의 링크와 기존 업체 리뷰/연결 데이터는 보존한다.

기존 private.merchants에 record_kind(business/source)를 추가한다. 기존 데이터는business로 유지하고 신규 기본값은source다. source는 관리자 내부 대리등록 자료이며 공개 회사 프로필·업체 리뷰가 없다. 기존 게시물/문의 링크는 계속 공개한다. 공개 업체 프로필·후기는 기존 공통 merchant_review_merchant 판정에 business 조건을 추가해 차단한다.

관리자 저장에 기존 save_admin_merchant RPC를 보존하고 record_kind를 명시하는 save_admin_merchant_record를 추가한다. 구형 저장도 신규source가 기본이므로 유령 회사가 자동 노출되지 않는다. 기존 리뷰 또는 연결된 소유 계정이 있는 업체는source로 변경할 수 없다. 기존 실제 업체의 기록·리뷰는 삭제하거나 초기화하지 않는다. 나중에 실제 업체가 확인되면 기존 회사에 글을 연결하거나 기록을business로 분류한다.

관리자 등록은 대리등록을 기본으로 하고 확인된 업체/매물·홍보 대리등록을 선택한다. 같은 화면에서 등록 이름과 공개 상태 설명을 구분하며 변경 컨트롤에 기존 선택 피드백을 적용한다. Apple Design의 명확한 선택 상태와 Mobbin Airbnb 유형 선택 화면(https://mobbin.com/screens/f99f5466-e3f5-4ade-a5d6-8d1f840f6e23)의 유형별 설명을 참조한다.

부동산은 기존housing/id14를 재사용해 게시글·필터 관계를 보존한다. 기본 해시태그 필터의 첫 두 항목은상업용/주거용이다. 임의로 기존 글 전체를상업용/주거용으로 분류하지 않는다. 이번 글의상업용시설 태그만상업용으로 수정한다.

검증은 등록 종류의 실제 렌더/피드백·저장 RPC·범주/필터 단위 검사, DB의 신규 기본source·유효한 저장·소유권/MFA·공개 profile/review 없음·원문 source 유지·기업 리뷰/계정 보존 guard를 rollback 검사한다. 실제 매물은 인증된 관리자 RPC로source 변경한 뒤 DB/공개 페이지를 다시 조회한다.20장 계약은 유지한다.

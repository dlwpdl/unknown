# 통합지도 카드·날짜·부동산 주소

2026-10-18 사용자는 통합지도 시안과 부동산 주소 표시를 승인하고 “너가 진행해”라고 요청했다. 기존 지도 레이아웃과 핀·목록·뒤로가기·공개 위치 경계는 유지한다.

- 일반 story는 지도에서 제외한다. 유효한 부동산/중고 listing, 정식 장소, 공급자 행사만 표시한다. 기존 글·매물을 복제하지 않는다.
- 장소는 이름·기존 사용 허가 사진, 매물은 등록된 가격·상품/매물 설명·공개 위치를 보여준다. 방 수·월세 주기·주소를 추정하거나 생성하지 않는다. 기존 장소 상세·후기와 매물 상세로 연결한다.
- 부동산 카드와 상세에는 기존에 공개로 첨부한 위치명/주소를 쓴다. 좌표·내 위치·선택한 위치만 있으면 상세주소 미등록을 표시한다. 비공개 프로필/GPS/본문에서 주소나 동호수를 추출하지 않는다. 새 동호수 공개 설정이나 주소 DB는 만들지 않는다.
- 행사 기본 기간은 해당 도시 오늘이다. 페스티벌 선택 시 다가오는 7일(오늘 포함)을 기본으로 하며, 직접 고른 기간/날짜는 분류 변경에도 유지한다. 초기화는 자동 기본값으로 돌아간다. 날짜 범위가 항상 보이고 기존 feedback을 유지한다.
- 명시적으로 전체 날짜를 고른 경우 기존 기능을 유지한다. 취소·종료 행사는 제외하고 기존 공급자가 전달한 여러 날 행사의 날짜 범위를 검사한다. 일부 날짜 요청 실패는 정상 결과를 지우지 않는다.
- 새 외부 데이터 공급자·Tripadvisor 가입/호출/계약·유료 서비스·DB 변경·새 자동화·배포·스토어 제출·최소버전 변경은 없다. 나이트라이프 필터는 검증된 장소 자료가 없으면 기존 빈 상태를 유지한다.

검증은 주소/기간/일부 실패/일반 글 제외/번역 단위·실제 컴포넌트 검사, typecheck/lint/full Node, 현재 React Native Web 컴포넌트의 한영·작은 화면 렌더로 한다. 기존 sole native owner가 실제 설치본과 source/hash를 확인하고 좁은 QA를 수행한다. 모의 브라우저 결과를 실기기 통과로 세지 않는다.

공급 범위: 기존 Ticketmaster 일별 조회와 페스티벌 캐시를 사용한다. 이미 시작된 장기 행사는 페스티벌 캐시 등 기존 응답에 포함된 경우 기간 교집합으로 표시한다. 이 변경은 공급자 데이터의 전체 행사 수록이나 종료 시각 정확도를 보장하지 않으며, 서버 조회 정책·새 공급자 도입은 별도다.

# Spec: 공유 유입과 익명 프로필 온보딩

## Objective

글을 외부 앱으로 공유하면 받는 사람이 로그인 없이 글을 먼저 보고, 공감·저장·댓글·대화 같은 상호작용 시 소셜 로그인과 프로필 생성을 마친다.

## Flow

`공유 버튼 → 운영 HTTPS 글 주소(없으면 gling 딥링크) → 게스트 글 보기 → 상호작용 → 소셜 로그인 → 프로필 선택 → 원래 행동 복귀`

프로필 선택:

- 소셜 계정 닉네임·사진 사용
- 직접 사진·닉네임 입력
- 한글 또는 영문 형용사+명사 두 단어 랜덤 닉네임

## Boundaries

- 공유 횟수는 공유 시트 성공 후에만 증가시키고 서버 연결 전에는 로컬 표시다.
- 운영 공유 주소는 `EXPO_PUBLIC_APP_URL`로 주입하며 주소가 없으면 앱 딥링크를 사용한다.
- 랜덤 닉네임은 2~20자 DB 제한을 지키고 생성 후에도 사용자가 수정한다.
- 게스트 공개 응답은 게시 중인 글의 표시 필드만 포함해야 하며 관리자·개인 데이터는 포함하지 않는다.

## Verification

- `npm run test:onboarding && npm run test:sharing && npm run typecheck && npm run lint`
- 공유 글 본문은 게스트에게 보이고 공감·저장·댓글은 로그인 모달을 연다.
- 로컬 관리자 우회와 달리 운영 인증·RLS는 우회하지 않는다.

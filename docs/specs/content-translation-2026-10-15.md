# 글·댓글 번역 — 2026-10-15

사용자가 한/영 앱 언어에 맞춰 게시글과 댓글을 읽도록 번역 기능 추가를 요청했다. 앞서 제안한 원문 보존, 번역 재사용, 수정 시 갱신을 승인한 후속 구현이다.

## 동작과 범위

- 기존 별도 app-language 작업본의 언어 선택 코드를 재사용한다. 원본 작업본은 수정하지 않는다.
- 로그인한 사용자가 글 제목·본문, 댓글과 답글을 한국어 또는 영어로 번역할 수 있다. 리스팅도 같은 게시글 경로를 사용한다.
- 자동 번역은 계정별 기기 설정에서 켤 수 있다. OpenAI 전송 목적을 알리고 처음 수동 사용 시에도 동의를 받는다. 설정되지 않은 상태에서는 외부 AI 호출이 없다.
- 자동 번역은 화면에 보이는 글·댓글부터 요청한다. 원문을 즉시 표시하고, 성공한 뒤 번역으로 전환한다. 원문 보기/번역 보기 전환을 제공한다. 수정·답글 작성·신고·공유·지도 링크에는 원문과 원래 ID를 사용한다.
- 실패·오프라인·서버 미배포 시 원문을 유지하고 재시도할 수 있다. 계정·언어·원문이 바뀌면 이전 응답을 표시하지 않는다.
- 번역 캐시는 원문 버전과 대상 언어별로 서버에서 재사용한다. 클라이언트의 임의 텍스트를 번역하지 않고 서버가 읽기 권한으로 조회한 저장 글·댓글만 번역한다.
- 삭제·차단·신고·부모 댓글 숨김·계정 정지·비공개 경계를 캐시 조회 전후에도 적용한다. 비로그인 전체 본문/댓글 접근을 넓히지 않는다. DM 번역과 이미지 속 글자 번역은 범위 밖이다.
- 지도·첨부·사진 출처·행사 참조는 기존 파서를 사용해 보존한다. URL·이메일·숫자·해시태그는 보호한 채 번역한다.

## 구현과 비용 경계

기존 Expo57/React19/RN0.86, AsyncStorage, Supabase, OpenAI Responses/gpt-5-mini를 재사용한다. 새 의존성·서비스·자동화는 추가하지 않는다. 서버 전용 키, store:false, 제한된 출력과 시간 제한을 유지한다. 원문/번역문/인증 정보를 로그에 남기지 않는다. 같은 원문·언어에 대한 동시 요청은 서버 임대로 한 번만 생성하며 실패 후 잠깐 재시도를 제한한다. 캐시 미스에 계정별 요청 한도와 프로젝트별 일일 문자 한도를 둔다.

새 마이그레이션은 로컬 검증하고 배포 파일로 준비한다. 운영 DB/함수·앱 배포와 실제 유료 API 호출은 이번 구현에 포함하지 않는다. 기존 전체 콘텐츠 안전 모니터링·관리자 권한·게시 일정은 그대로 유지한다.

## 구현 순서와 검증

1. 번역 계약·보호 값·캐시/RLS/동시 요청 검사를 실패하는 테스트로 작성한다.
2. 인증·원문 조회·캐시·생성 핸들러와 로컬 SQL을 구현하고 검증한다.
3. 기존 언어 설정과 계정별 자동 번역 설정, 글/댓글 표시를 연결한다.
4. 실제 컴포넌트를 격리된 예시 데이터로 렌더하고 한/영·원문 전환·실패·화면 크기·접근성·편집 원문 보존을 확인한다.
5. 타입·변경 lint·관련 테스트·전체 Node 검사·네이티브 JS export를 검증하고 파일 링크로 리뷰 화면을 제공한다.

공식 문서 확인: https://docs.expo.dev/versions/v57.0.0/ ,
https://developers.openai.com/api/docs/guides/structured-outputs ,

## 최종 검증과 남은 범위

- 전체 Node 검사 894개 중 892개 통과, 기존 제외 2개. 새 번역 검사 23개 통과. 타입 검사와 변경 TypeScript 파일 lint 통과.
- 실제 로컬 Postgres에서 캐시·임대·한도·원문 수정/삭제·차단/부모 댓글 숨김 RLS를 검사했다. 단일 트랜잭션을 rollback한 뒤 번역 테이블이 남지 않은 것도 확인했다. 별도 연결을 사용한 동시 부하 시험은 수행하지 않았다.
- iOS와 Android의 JavaScript export를 생성했다. 검수용 계정·키·응답 fixture가 배포 코드 묶음에 없음을 확인했다. 서명 빌드·실기기·VoiceOver·실제 진동과 음성 피드백은 검증하지 않았다.
- 실제 PostCard·PostDetail·댓글·언어 설정 컴포넌트를 격리해 렌더했다. 한/영 전환, 원문/번역문 독립 전환과 추가 요청 없음, 화면에 들어온 답글 번역, 수정 입력의 원문 유지와 취소, 자동 번역 해제 시 요청 없음, 실패 시 원문 유지와 재시도, 카드 320px 폭의 가로 넘침 없음과 44px 번역 버튼을 확인했다. 편집 검사에서 입력 focus만 fixture 안에서 억제해 다른 작업의 키보드 입력을 보호했다.
- 검수 응답은 사람이 지정한 예시이며 실제 OpenAI 호출은 0회다. 최초 동의 Alert의 실기기 동작과 실제 번역 품질·속도·요금은 미확인이다. 이미지 생성/편집은 사용하지 않았다.
- 언어 작업본에서 provider·사전·LanguageCard 6개 파일만 재사용했다. 화면별 기존 UI 문구 전체의 영어 이식은 이번 변경에 포함되지 않는다.
- 초기 생성 한도는 UTC 하루에 계정당 200회, 프로젝트 전체 입력 100,000자다. 캐시 적중은 생성 한도를 사용하지 않는다. 문자/요청 제한은 달러 금액의 보장 한도가 아니며 운영 사용량은 아직 없다.
- 운영 DB 마이그레이션, Edge Function 배포, 앱 배포는 하지 않았다. 기존 배포 보류를 유지한다. 실제 활성화 시 서버 전용 OPENAI_API_KEY와 함수 연결을 확인해야 한다.

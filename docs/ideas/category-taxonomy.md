# 글링 대분류 + 해시태그

## Problem Statement

캐나다 한인 사용자가 지역 피드에서 원하는 생활 주제를 빠르게 찾되, 세부 주제마다 피드가 쪼개지지 않게 한다.

## Recommended Direction

필터와 글쓰기는 `라이프·맛집·여행·쇼핑·정착·이동·주거·교육·모임` 9개 대분류를 공통 사용한다. 워홀·핫딜·렌트처럼 계속 늘어나는 세부 주제는 자유 해시태그로 표현한다.

## Key Assumptions to Validate

- [ ] 9개 대분류가 가로 스크롤에서 빠르게 탐색된다.
- [ ] 사용자가 세부 주제를 해시태그로 자연스럽게 입력한다.
- [ ] 초기 피드 밀도가 대분류별로 지나치게 낮아지지 않는다.

## MVP Scope

- 피드 대분류 필터와 글쓰기 대분류 선택
- 기존 글의 새 대분류 이관
- 피드와 글쓰기에서 실제 사용 빈도순 인기 해시태그 노출
- 새 대분류에 글이 적을 때 사용할 기본 해시태그 제안

## Not Doing

- 소분류 선택 UI — 해시태그로 충분하다.
- 카테고리별 정형 폼 — 사용 패턴을 보기 전에는 과하다.
- 모임 외 자동 대화방 — 일상 공유 중심 범위를 유지한다.

## Open Questions

- 실제 사용량을 본 뒤 대분류 순서를 인기순으로 조정할지 결정한다.

## 검증 기록

2026-10-14 최종 소스에서 Node 988개 중 987개 통과, 기본 조건부 export 검사 1개는 별도 환경 변수를 지정해 1개 통과했다. SQL은 기존 PostgreSQL17 컨테이너의 단일 트랜잭션에서 58개 통과 후 rollback했다. 타입·전체 lint·공개/업체 export와 관리자 코드 제외 검사, 비공개 관리자 export가 통과했다.

실제 Expo 관리자 export를 390/1440px의 격리된 headless 브라우저에서 렌더했다. 예시 응답으로 여덟 영역·0/미수집/관측 중·필터·차트/표·권한 오류/재시도·이전 응답 제거와 포커스된 표의 좌우 방향키 이동을 확인했다. 모든 HTTP/WebSocket 외부 연결은 mock 또는 차단했으며 운영 계정 로그인이나 실제 성과 증거로 사용하지 않는다. 실제 MFA 세션 정의와 권한·탈퇴 삭제는 SQL 검사에서 별도로 검증했다. 실제 단말의 푸시 수신·소리·햅틱과 네이티브 crash-free 비율은 미검증이다.

기술 검토에서 확인된 일반/업체 결제 혼입은 기존 RevenueCat 상품 계약에 맞춰 수정하고 실패 회귀→통과를 확인했다. 회원이 도시를 바꾼 뒤에도 알림 클릭 분자와 수신 회원 분모가 같은 조건을 따르도록 수정했다. 행사·장소는 실제 대상 도시를 유지한다. 새 RPC의 공개/업체 번들 유출 검사도 실제 실패 후 통과했다.

원자료·운영 정의·dry-run/rollback·worker 소유권 영수증은 기존 비공개 `~/Library/Application Support/gling/operations/admin-performance-20261014/`, 로컬 검사 로그는 `.release/`에 둔다. 기존 원본 작업 폴더의 수정·자동화 원장과 검수 자료는 이 커밋에 섞지 않는다.

## 기존 관리자 개편 통합

기존 관리자 서버가 제공하던 원본 작업 폴더에서 완료된 별도 관리자 개편을 확인했다. 단독 분석 export를 잠시 연결한 뒤, 해당 개편이 빠진 것을 확인해 이전 export를 복원했다. 담당자의 `msg_a295baed6c39` 인계로 쓰기 종료, 소스18개·검사9개의 최종 경계/hash를 확인하고 비공개 operations에 원본 스냅샷을 저장했다. 원본 checkout은 수정하지 않고 이 브랜치에서 분석 컴포넌트를 3-way 병합했다.

운영 현황 첫 화면, 모임 목록·상세·해당 모임 대화, 전역 대화 목록·페이지, 회원의 핵심 정보와 기술 정보 펼침을 유지한다. 기존 대화 위험 신호·검토 API와 훅·패널도 보존했다. 새 모임/대화 읽기 도우미는 `admin-conversation-messages.ts`로 옮겼고, 전역 목록 아래에서 기존 검토 화면을 명시적으로 펼칠 때만 불러온다. 닫아도 작성 중인 검토와 목록 필터는 유지한다. 모임 안의 목록과 로컬 preview에서는 전역 검토를 열지 않는다.

통합본 전체 Node 검사1007개 중1006개 통과·조건부1개 skip, 조건부 export 검사는 별도1개 통과했다. 타입·전체 lint·공개/업체 export와 비공개 코드 제외 검사, 비공개 관리자 export가 통과했다. 390/1440px 실제 Expo export의 격리된 예시 응답 검사도 다시 통과했다. SQL 변경은 추가하지 않았고, 이미 검증·반영한 migration `20261014210000`과 기존14개 작업의 일정/소유권을 유지한다.

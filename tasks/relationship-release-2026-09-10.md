# Gling 관계 슬롯 출시 — 2026-09-10

## 구현과 서버 적용

- 모임과 1:1 동시 슬롯을 무료/플러스/프리미엄 3/5/10으로 분리했다. 글 작성은 하루 1/2/5편이다.
- 1:1 요청은 상대의 명시적 수락 뒤 양쪽 슬롯을 동시에 사용한다. 종료 시 최초 요청자 한 자리만 24시간 잠기며 수락자는 즉시 반환한다. 수락 전 메시지 접근과 전송을 차단한다.
- 모임 신청은 방장 승인 뒤 공통 단체대화로 연결한다. 자발적 탈퇴는 탈퇴자 모임 한 자리를 24시간 잠근다. 방장 해산은 방장만 잠기며 수동 참여자는 즉시 반환한다.
- 신고/차단/탈퇴와 전체 콘텐츠 안전 분석·관리자 접근 감사 범위를 유지했다. 차단한 그룹 메시지도 참여 당시 접근 가능한 메시지라면 신고할 수 있다.
- 기존 최초 요청자 기록이 없는 1:1은 보존하고 소급 잠금을 부과하지 않는다.
- 운영 Supabase에는 `0033_relationship_slots.sql`만 적용했다. 적용 전 public/private 스키마·데이터를 로컬 접근 제한 파일로 백업했다. 운영 확인: 기존 1:1 1개 보존, 공유 모임 대화 6개 생성, 메시지 안전 트리거와 관리자 RLS 유지.
- 캐시·끌어올림 소스는 보관하되 출시 빌드에서 메뉴/경로/API 호출이 열리지 않는다. 관련 SQL·테스트는 `supabase/deferred/`에 두었으며 운영 DB·RevenueCat 상품·웹훅으로 배포하지 않았다.

## 남은 출시 조건과 복구

- iPhone X 연결은 오프라인이라 실기기 설치 확인을 하지 못했다.
- Apple 구독 4개는 메타데이터 미완료 상태이며 이번 앱 심사에 구독 판매를 함께 제출하지 않았다. 심사 안내에 구독 판매 준비 중과 크레딧/홍보 미노출을 명시했다. 실제 스토어 결제 검증은 별도 작업이다.
- Google 공개 출시는 타겟층·데이터 보안 설정과 12명 이상 14일 비공개 테스트가 남았다. 현재는 내부 테스트이며 공개 출시 완료가 아니다.

- 문제 시 스토어 제출/내부 배포를 중단하고 수정 빌드를 올린다. 동의 없는 옛 대화 생성 경로로 서버만 되돌리지 않는다. 기존 데이터와 새 동의/잠금 기록을 보존하는 전진 수정이 우선이다. 백업 전체 복원은 배포 후 데이터 손실 위험 때문에 자동 실행하지 않는다.

# 행동 분석 구현 (2026-09-21)

요청: 앱의 버튼 행동, 화면 이동, 체류, 스크롤과 가입/모임 참여 단계를 기존 관리자 분석에서 확인한다. 공개 웹도 별도로 집계한다.

- 기존 Supabase/private 저장소와 관리자 UI 재사용, 외부 SDK/의존성 추가 없음.
- 고정 식별자만 허용. 버튼 텍스트, 입력값, 검색어, URL, 글/대화/사진 내용은 전송하지 않는다.
- 화면 방문, 활성 상태 체류 시간, 스크롤 25/50/75/100%, 버튼 클릭, 성공한 업무 단계 기록. 클릭은 성공과 구분한다.
- 원자료 90일, 회원 삭제 시 연결 자료 삭제. 관리자 권한 및 감사 기록으로 조회.
- 익명 웹은 메모리 세션만 사용하고 회원과 연결하지 않는다. 읽기 전용 콘텐츠 클라이언트와 수집 전송 분리.
- 배치/메모리 큐 제한, 중복 방지, 서버 입력 검증 및 호출 제한. 분석 실패는 사용자 작업을 막지 않는다.
- 순서/화면별 집계 제공. 단계별 발생 수는 순서 기반 전환율로 오인하지 않도록 명시한다.

검증: npm test, npm run typecheck, npm run lint, npm run export:web, npm run check:public-web 및 SQL 권한/검증/집계 테스트. 네이티브는 새 빌드에 포함돼야 배포 사용자에게 적용된다.

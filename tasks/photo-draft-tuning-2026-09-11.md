# 사진 기반 개인 글 초안

- 사진 설명 대신 작성자의 힌트·카테고리·말투를 먼저 반영한다. 힌트가 없으면 짧은 생각이나 질문으로 시작하고 방문·구매 경험은 만들지 않는다.
- 작성 규칙은 Responses API의 `instructions`, 사용자 힌트는 입력 데이터로 분리했다. 기존 동의·인증·사용량 제한과 `store: false`를 유지한다.
- `node --test scripts/draft-post.test.mjs` 통과. 같은 콜하버 사진으로 실제 모델을 비교했다. 기존의 사물·배경 설명이 산책 장소를 묻는 짧은 개인 글로 바뀌었다. 힌트를 준 경우 힌트의 작성 목적을 반영했다. 생성 결과에는 변동성이 있으며 게시 전 사용자가 수정할 수 있다.
- 2026-09-11 Supabase `draft-post` 배포 완료. 네이티브 앱 업데이트 없이 기존 빌드에서도 적용된다. 실제 인증된 함수 호출 HTTP 200을 확인했으며 테스트 게시물은 발행하지 않았다.

사진: 저장소의 `assets/seed/vancouver-coal-harbour.jpg`와 기존 출처 정보를 사용했다.

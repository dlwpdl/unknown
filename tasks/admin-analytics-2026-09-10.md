# 글링 관리자 분석 · 2026-09-10

운영 주소: [글링 관리자](https://gling.ej-entertainment.com/admin). 사전에 등록된 관리자 이메일 계정으로 로그인한다. 일반 회원과 심사 계정은 접근할 수 없다. 앱의 회원 가입 경로는 바꾸지 않았다.

## 반영 내용

- 기존 관리자 콘솔에 분석을 첫 화면으로 추가했다. 7/30/90일, 도시, 현재 멤버십 필터와 내부 계정 포함 여부를 제공한다. 목·심사·관리자 계정은 기본 집계에서 제외한다.
- 회원 수·가입·작성 글·현재 멤버십·도시 분포, 회원 목록·최근 로그인, 로그인 회원의 방문·화면 조회·실제 중복 제거 글 조회를 연결했다.
- 인증된 RevenueCat 이벤트를 기록하고 운영 결제만 통화별로 집계한다. 이벤트 ID와 거래 ID 중복, 테스트 결제를 제외한다. 환불·수수료 차감 전 결제 발생액이며 정산액이 아니다.
- 관리자 접근 감사 기록과 안전 분석 실패를 표시한다. 기존 전체 콘텐츠·대화의 안전 운영 범위와 권한을 유지한다.
- 접속 원자료는 비공개 테이블에 저장하며 90일 정리 작업을 적용했다. 계정 삭제에 연동된다. IP·검색어·대화 원문·URL 쿼리는 통계에 저장하지 않는다.

- Supabase `0031_admin_analytics` 마이그레이션과 `membership` 함수를 운영에 배포했다.
- 수집 시작: **2026-09-10 21:05:14 UTC**. 그 이전 방문은 미수집으로 표시한다. 웹 방문 수집은 새 웹 배포 이후, iOS·Android 방문 수집은 다음 앱 빌드 설치 이후 시작된다.
- 전체 Node 검사 57개, DB 검사 21개 파일의 231개 테스트 통과. 타입 검사와 ESLint, 최종 웹 내보내기 24개 경로 통과.
- 실제 운영 API: 익명 분석 조회 401, 심사 계정 분석 조회 `ADMIN_REQUIRED`, 일반 계정의 결제 기록 생성 거부를 확인했다. 원자료 접근 권한과 90일 정리 작업 활성 상태도 확인했다.

## 남은 연결

**카카오 연령대**: 글링 앱 1558027은 현재 `age_range` 권한이 없다. 신청 자격 확인을 마쳤고, 비즈니스 정보 심사 폼에 서비스 주소와 설명을 입력했다. 필수 사업자 증빙이 없어 제출하지 않았다. 사업자 정보 승인 이후 개인정보 동의항목 권한 신청이 필요하다. 승인 전에는 로그인 scope를 추가하지 않았다. 연령대는 현재 모두 미확인이며 실제 수집·보관 기능도 아직 켜지지 않았다.

입력한 서비스 주소는 `https://gling.ej-entertainment.com`이다. 설명은 캐나다 한인 커뮤니티, 지역 게시판·모임·1:1 대화·선택적 멤버십, 출시 준비 중, 연령대 선택 동의·미동의 기본 이용 가능, 비공개 집계와 서비스 개선 목적, 생년월일·실명 인증 목적이 아님을 명시했다.

서비스 증빙 화면으로 기존 스토어용 실제 앱 캡처 `release/google-play/phone/01-vancouver.png`를 확인 후 첨부했다. 사업자 증빙은 앱에 등록된 사업자 정보와 일치하는 실제 문서가 필요하다. 폼은 Git → gling의 카카오 개발자 탭에 남겨 두었다.

**글 끌어올리기**: 유료 상품과 노출권 집계는 아직 미구현이다. 진행 글·목표 노출·남은 노출·구매 순위는 미연결로 표시한다. 자연 조회수를 유료 노출 실적으로 바꾸지 않는다.

**실사용 확인 범위**: 운영의 실제 관리자 비밀번호는 사용하지 않았다. 브라우저는 로컬 미리보기와 비관리자 차단, 자동 검사는 실제 SDK·서버 함수로 검증했다. 실제 관리자 로그인 뒤 운영 데이터가 표시되는 최종 확인은 남아 있다. 과거 구매 내역을 역으로 채우거나 실제 스토어 결제를 실행하지 않았다.

이 관리자 분석 변경 커밋을 revert하고 `mobile-app`을 푸시하면 이전 웹이 다시 배포된다. 결제 이벤트 기록에서 문제가 생기면 이전 커밋의 `membership` 함수를 재배포한다. 새 비공개 테이블과 이미 수집한 기록은 삭제하지 않는다. 기존 회원·구독·안전 운영 테이블을 되돌릴 필요는 없다.

# 글링 1.0.0 (10)

Google 로그인을 기존 PKCE 흐름에 추가하고 모임·1:1 대화의 연속 막대 슬롯 UI를 새 네이티브 빌드에 포함한다. 멤버십은 현재 상태와 남은 자리부터 보여주고 상세 규칙·상품 비교는 펼쳐서 확인한다. 무료/플러스/프리미엄의 서버 제한과 24시간 잠금 규칙은 유지한다.

- Google Cloud `gling-app-dlwpdl`: 외부 사용자 Production, openid/email/profile만 요청. Supabase Google 공급자와 migration 0034 적용. 실제 Google 인증 완료 확인.
- iOS 인증 시작은 기존 글링 도메인 페이지를 사용한다. Google 인증 화면의 표시 이름은 별도 브랜드 검증이 필요하며, 홈페이지 소유권 인증 파일을 포함했다.
- 확인된 Google identity `eun530k@gmail.com`에만 서버 admin 역할을 부여했다. 기존 관리자 계정은 유지한다. 재로그인/토큰 갱신 후 권한이 반영된다.
- 관리자 전용 export에도 인증 콜백을 제공한다. 로컬 서버가 확장자 없는 콜백 URL을 처리하고 이전 export의 HTML을 캐시하지 않도록 했다. 127.0.0.1에만 바인딩한다.
- RevenueCat 상품 조회 실패가 멤버십 동기화를 막던 문제를 수정했다. 서버 멤버십을 먼저 동기화하고 오래된 결제 상품을 비운다. 결제·계정 변경 보호는 유지한다.
- AI 사진 초안의 개인 게시글 중심 프롬프트는 앞선 `81bb996`에서 별도 배포했다.

검증: JS 테스트 75개, 타입 검사, 린트 통과. SQL 22개 파일/307개 검사 통과. 멤버십 UI의 모바일·태블릿·다크·확대 글자 검증 및 iOS Release 실행 확인. `python3 scripts/test_admin_server.py`로 콜백/경로 처리 검사.

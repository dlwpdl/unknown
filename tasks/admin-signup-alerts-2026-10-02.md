# 신규 가입 관리자 알림

사용자 요청: 신규 가입 시 관리자 대시보드와 관리자 앱에 알림.

- 기존 가입 RPC의 프로필 최초 생성·필수 동의 완료가 기준이다. 로그인, 프로필 수정, 재동의·재활성화는 신규 가입으로 세지 않는다.
- 서버에서 활성 admin 계정에만 `admin_signup` 시스템 알림을 한 번 생성한다. 미완료·익명·시드 프로필은 제외한다. 기존 알림·푸시 큐·설정·권한을 재사용한다.
- 대시보드 전체 섹션에 읽지 않은 가입 알림을 표시하고 회원 상세 보기와 확인을 제공한다. 실시간 변경과 30초 재조회/복귀로 연결 끊김을 보완한다.
- 앱의 기존 관리자 알림함·배지·푸시를 그대로 사용한다. 기기 등록·푸시 허용이 없으면 앱 알림함에 남으며 실제 푸시 수신을 주장하지 않는다.
- 본문은 닉네임과 도시만 포함하며 이메일·실명·생년월일·IP는 노출하지 않는다. 동의, 관리자 감사, 기존 안전 감시 범위를 유지한다.
- 기존 미커밋 작업을 보존한다. 새 마이그레이션만 배포하고 관리자 웹만 갱신한다. 기존 가입자 소급 알림·새 앱 스토어 출시·새 유료 서비스는 범위 밖이다.

검증: 실제 Postgres 트랜잭션/pgTAP으로 가입·중복·권한·롤백·푸시 큐를 검사한다. 실제 컴포넌트의 표시/실시간/재조회/확인 실패/정리 동작을 Node 테스트로 검사한다. 타입 검사·관련 회귀 검사 후 관리자 웹을 렌더한다.

롤백: 신규 프로필 알림 트리거만 제거하면 추가 발생이 중단된다. 기존 알림·푸시·관리자 기능은 유지된다.

UI 참고: [Dialpad 상단 상태 배너](https://mobbin.com/screens/d45c4a5b-81d0-4f71-a374-423badb62035), [Ditto 알림 목록](https://mobbin.com/screens/3197702d-5f60-4582-b091-cb9a2bea2cf3). 방해하는 모달 대신 기존 밝은 관리자 테마의 작은 상태 영역을 사용한다. 새 행동에는 기존 interaction feedback을 연결한다.

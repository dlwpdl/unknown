# Threads 초안 — 글링 소개 시리즈 (2026-09-22)

목적: Threads 글은 전부 글링 이야기로 채운다. 얕게 시작해서 깊게 들어가는 순서로 쓴다.
말투: `voice.md` 반말·자조. 계정은 @gling.app(창업자 목소리).
본문에 링크·설치·가입 요청은 넣지 않는다. 유입 경로는 이름 각인 → 프로필 방문 → 프로필 소개 링크다.
발행은 사용자 재개 지시 전까지 하지 않는다.

## 얕게 — 1. 이름만 던지기

```text
쓰친들아 글링이라는 앱 들어봤어?
나는 만드는 사람이라 물어보면 좀 웃긴데
자기가 만든 앱 검색해서 남들이 뭐라 하나 보는 중임
아직 아무도 안 씀 (당연함)
궁금한 거 있으면 물어봐줌
```

## 얕게 — 2. 문제부터 던지기

```text
쓰친들아 이런 앱 있으면 쓸 것 같음?
새로 이사 간 동네에서 "근처에 밥 먹을 데" 물어볼 곳이 없어서
검색하면 광고, 카페는 가입 승인 대기
그래서 만드는 중임. 이름은 글링
```

## 얕게 — 3. 한 줄 설명

```text
글링을 한 줄로 말하면
허락 안 기다리고 동네 사람한테 바로 물어보는 앱임
가입 승인 기다리는 구조를 없애려고 만듦
지금은 밴쿠버·토론토·몬트리올·에드먼턴 네 곳부터
```

## 중간 — 4. 만들면서 제일 많이 고민한 것

```text
글링 만들면서 제일 많이 고민한 건 규칙을 어디까지 둘까였음
다 열어두면 도배가 오고, 규칙을 세우면 문을 막게 됨
그래서 문은 안 막고 문제만 막는 쪽으로 정했음
이거 판단 맞는지 아직도 모르겠음
```

## 중간 — 5. 이름에 넣은 뜻

```text
앱 이름 글링에 뜻을 넣었음
G는 Gate가 아니라 Go라는 뜻임. 문을 막는 쪽이 아니라 나아가는 쪽
한국어로는 글이 사람을 잇는다는 뜻도 같이 넣음
이름 붙이는 데 반나절 걸렸는데 마음에 듦
```

## 중간 — 6. 사업자를 막지 않기로 한 이유

```text
글링 규칙에 "사업자라도 막지 않는다"를 넣었음
대신 도배·기만·과한 홍보는 관리함
왜 이렇게 나눴냐면 문제는 사업자가 아니라 다른 사람 공간을 침해하는 행동이라서
돈 버는 사람을 쫓아내는 커뮤니티는 결국 조용해진다고 봄
```

## 깊게 — 7. 테스터 반응 먼저 받기

```text
테스터 한 명에게 먼저 써보게 했음
내가 만든 거라 내 눈엔 다 좋아 보여서 써본 사람 말이 제일 무섭고 제일 도움 됨
반응 오면 좋은 말이든 아니든 그대로 올림
```

## 깊게 — 8. 지금 상태 공개

```text
글링 현재 상태
앱은 돌아가고, 도시 4곳 생활 정보는 매일 쌓이는 중
스토어 공개는 아직 전임
공개되면 여기서 먼저 말함
궁금한 거 있으면 댓글로 물어봐줌
```

## 사용자 요청 원고 — 왜 만들었는지부터 (2026-09-22)

사용자가 직접 제시한 방향: 캐나다에서 쓰는 커뮤니티가 안 맞아서 또래용으로 만들었다, 한번 볼래.
세 가지 길이로 쓴다. A와 B는 `올드하다`를 쓰는지가 다르고, C는 첫 줄만 짧게 던지는 형식이다.

### A. 원문 살린 버전

```text
쓰친들아
캐나다 현지에서 쓰는 커뮤니티가 나랑 좀 안 맞아서
내 또래 친구들 쓰라고 하나 만들었음
가입 승인 기다리는 거 없애고, 검색해도 안 나오는 동네 얘기 하려고
한번 볼래?
```

### B. 직설 버전 (사용자 표현 유지)

```text
쓰친들아 여기서 쓰는 커뮤니티들 좀 올드하다고 느꼈음
가입 승인 기다리고, 규칙은 안 보이고, 글 하나 쓰기까지 오래 걸림
그래서 내 또래가 바로 쓰는 걸 만들어봤음
한번 볼래?
```

### C. 짧은 버전

```text
쓰친들아 캐나다에서 쓰는 커뮤니티가 너무 올드해서
내 또래 쓰라고 하나 만들었음
한번 볼래?
```

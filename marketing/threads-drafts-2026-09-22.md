# Threads 초안 — 2026-09-22

말투는 `voice.md` 기준(반말, 자조, 쓰친들 호칭은 가끔). 발행은 사용자 재개 지시 전까지 하지 않는다.
직접 링크·설치·가입 요청은 넣지 않는다. 아래 8개는 창업자 계정(@gling.app) 1인칭으로 쓰는 원고다.

## 1. 혼밥 자리

```text
쓰친들아 혼밥할 곳 추천받을 때 메뉴만 물어보고 끝내는 편임
근데 가서 아쉬운 건 자리임. 혼자 앉기 편한지, 빨리 먹고 나오기 좋은지
이거 같이 물어보면 훨씬 덜 헤맴 (나는 늘 빼먹음)
혼밥할 곳 고를 때 제일 먼저 보는 거 뭐임?
```

## 2. 앱 이름 뺏길 뻔한 이야기 (실제 겪은 일)

```text
쓰친들아 앱스토어에 이름 올리려다 뺏긴 줄 알았음
"글링"이 이미 쓰이고 있대서 뒤에 "캐나다 한인 커뮤니티"를 붙여야 했음
이름 하나 정하는 데도 이렇게 걸리는구나 싶었음
앱 이름 정할 때 뭐 제일 봄?
```

## 3. 가입 승인 기다리는 문제

```text
쓰친들아 한국 커뮤니티 앱 하나 만들어보고 있는데
제일 많이 듣는 말이 "가입 승인 언제 나요"임
그거 없애려고 만드는 중임. 규칙은 있는데 문은 안 막는 쪽으로
이거 만들면 씀?
```

## 4. 검색으로는 안 나오는 질문

```text
쓰친들아 이런 거 어디에 물어봄?
검색하면 안 나오고, 맘카페는 가입 승인 기다려야 하고, 아는 사람한테 물어보기엔 애매한 거
예를 들면 "이 동네에 혼자 밥 먹기 편한 데" 같은 거
다들 어디서 해결함?
```

## 5. 확인되는 정보 먼저 주기

```text
밴쿠버 쓰레기 버리는 날은 주소 넣으면 나옴. 시 안내에 있음
그런데 "이 동네에 그거 아는 사람 있냐" 같은 건 검색으로 안 나옴
확인되는 건 정리해서 올리고 있음
이런 거 찾다가 못 찾은 거 있음?
```

## 6. 테스터 후기 요청 (진짜 증거 만들기)

```text
쓰친들아 테스터 한 명 모셔서 써보는 중인데
써본 사람이 뭐라고 하는지가 제일 궁금함
내가 만든 거라 내 눈엔 다 좋아 보여서
써본 사람 있으면 어땠는지 알려줄 수 있음?
```

## 7. 첫 겨울, 동네 세 개

```text
이사 오고 첫 겨울에 좀 가라앉았는데 그거 다들 겪는 거였음 (나만 그런 줄 알았음)
해 짧아지는 게 제일 큼. 4시에 깜깜해지는데 며칠 보면 좀 내려감
그래서 밖에 나갈 이유를 미리 만들어놓음. 카페든 산책이든
너네는 겨울에 뭐 하면서 버팀?
```

## 8. 내가 만든 앱을 내가 쓰는 이야기 (후기처럼 읽히는 창업자 목소리)

```text
내가 만든 앱을 내가 쓰는 게 좀 웃긴데
요즘 제일 자주 누르는 건 동네 사람한테 물어보는 칸임
검색하면 안 나오고 아는 사람한테 물어보기 애매한 거, 거기다 씀
혼자 쓰고 답 없으면 좀 허무함 (그래서 만드는 중)
이런 거 궁금해하는 사람 있음?
```

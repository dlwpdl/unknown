# 글·사진 벤치마크 링크 대기함

Instagram 사진·캐러셀 또는 Threads 글의 URL을 `대기` 아래에 **한 줄에 하나씩** 붙여 넣는다. 맨 앞의 `- `는 있어도 없어도 된다. 공개 조회수가 보이지 않으면 URL만 넣어도 된다. 조회수 숫자나 게시물 인사이트를 알고 있다면 URL 바로 아래에 `조회수: 숫자 (출처와 확인 시각)`을 적는다. 숫자만 전달된 경우에는 검증된 조회수로 취급하지 않는다. 릴스·영상은 이 대기함이 아닌 튜브벤치 대상으로 둔다.

기존 글링 20:00 자동화가 **대기 URL이 있을 때만** 해당 링크를 열어 [분석 기준](text-photo-benchmark-plan-2026-09-29.md)에 따라 로컬 분석 카드를 만든다. 결과를 저장한 뒤 해당 URL을 `처리 완료`로 옮긴다. 접근 실패나 확인 불가 항목은 `대기`에 남긴다. 이 파일은 SNS **발행 큐가 아니다**.

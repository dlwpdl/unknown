# 도시 정보 원고 — 2026-09-21

상태: 2026-09-21 사용자 요청으로 운영 DB에 40개 게시 완료. 별도 조회로 도시별 10개, 날짜, 닉네임, 활성 프로필, 안전 검토 큐를 확인함. 결과: `publication-verification.json`.

밴쿠버·토론토·몬트리올·에드먼튼 각 10개. 닉네임 40개 모두 다름.
도시 간 닉네임 공유 금지. 기존 가입자와의 닉네임 중복도 금지하며, 등록 직전에 SQL 검증으로 재확인하고 충돌 시 전체 등록을 중단함.
조회수 20~300에서 생성한 초기 샘플 값으로 실제 조회 집계가 아님.
각 글 본문의 출처는 작성일에 조회한 공식 기관·시설 안내.
개인 방문 경험, 구체적인 현재 날씨, 검증되지 않은 가격·행사 일정은 작성하지 않음.

몬트리올 활성화: 운영 DB 0075 적용. 앱 소스 반영. 설치 앱은 새 빌드 필요.

검증 명령(트랜잭션 종료 시 모든 글·프로필·검토 큐 삽입을 롤백):

```sh
npx --no-install supabase db query --linked --file content/2026-09-21/import-preview.sql --output json
```

고정 UUID로 재실행 시 중복 글을 만들지 않음. 실제 계정은 재사용하지 않음.
기존 seed 계정 패턴과 공개 프로필 소개로 합성 데이터를 구분하며 안전 검토 트리거를 유지함.

랭킹 보완: 0078 적용. 목 조회수의 누락된 활동 기록을 보완하고, 목 작성자도 주간 순위에 포함. 이번 주 4개 도시별 상위 10개를 재집계했으며 공개 RPC로 확인함 (`ranking-verification.json`). 등록 SQL도 신규 글의 초기 조회 기록을 함께 생성하도록 수정. 주간 고정·7일 활동 집계 방식은 유지.
